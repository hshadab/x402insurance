How It Works▸
1

Buy Coverage

Agent sends POST /insure with x402 payment. Premium is 1% of coverage. Settled on-chain via x402.org facilitator.

2

API Fails

Merchant returns HTTP 500+ or empty response. Agent captures full HTTP response as evidence.

3

Claim & Prove

POST /claim triggers server re-fetch for fraud detection, then Jolt Atlas generates a zkML proof over ONNX model inference.

4

Verify & Refund

zkML proof verified. If valid, USDC refund sent on Base Mainnet. Proof auditable via POST /verify.

x402 Payment Flow

        

            

                
1
POST without payment
Server responds 402 with accepts array.

                
2
Sign EIP-712 typed data
Build payment message, sign with wallet key.

                
3
Retry with PAYMENT-SIGNATURE header
Server verifies via x402.org facilitator, settles on-chain.
